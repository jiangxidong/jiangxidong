I design and ship AI-native products — from real-time voice coaching apps and private, on-device iOS experiences to open-source agent skills and PM operating systems.

## What I Work On

- **AI-Native Products**: Real-time voice agents ([Articulate](https://github.com/jiangxidong/articulate) on Gemini Live API) and private, on-device AI iOS apps ([HabitCopilot](https://jiangxidong.github.io/habitcopilot-site/) on Apple Foundation Models)
- **Agentic Workflows & Skills**: Open-source skills for Claude Code & Codex covering multi-stage workflows, image style prompting, knowledge synthesis, and solo-founder playbooks
- **PM Operating Systems**: Structured agentic frameworks ([PM-OS](https://github.com/jiangxidong/pm-os)) that bring engineering rigor to product operations
